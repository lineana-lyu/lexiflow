# Security Policy

## Supported versions

Security fixes are applied to the latest published LexiFlow release and the
current development branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting / Security Advisory feature
for the `lineana-lyu/lexiflow` repository. Do not publish authentication data,
API keys, personal learning data or working exploit details in a public issue.

Include the affected version, reproduction conditions, expected impact and any
suggested mitigation. The maintainer will acknowledge a valid report, assess its
severity and coordinate a fix before public disclosure when practical.
