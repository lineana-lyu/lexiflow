# Contributing to LexiFlow

Thank you for helping improve LexiFlow.

## Before submitting a change

1. Open an issue for substantial product or architecture changes.
2. Keep the local-first privacy boundary and the five-stage learning flow intact.
3. Run `npm ci` and `npm run check`.
4. Explain the user problem, expected behavior and verification in the pull request.

All pull requests from non-maintainers require maintainer review before merge.
Build, packaging, dependency, privacy and signing-policy changes receive explicit
review because they affect release trust.

Unless explicitly stated otherwise, contributions intentionally submitted for
inclusion in LexiFlow are licensed under the Apache License 2.0, consistent with
the repository license.
